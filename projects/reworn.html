REWORN

Angular Express PostgreSQL Supabase

About the project

One item reworn. One story retold. REWORN is a fictional second-hand clothing shop built with Angular, where one-of-a-kind finds get another chance instead of another trip around the trend cycle.

What I built

Everything. Angular frontend with signals-based state management, a shared CartService for session-persistent cart, and seven page components. On the backend, an Express API following the Repository Pattern with parameterized queries, connected to a PostgreSQL database on Supabase. SKUs and slugs are auto-generated server-side. Deployed with the frontend on Vercel and backend on Render.

Challenges

This was my introduction to Angular, so a lot of the challenge was learning the framework while building something real at the same time. Understanding the difference between signals and RxJS, when to use a service versus a component, and how environment files work for routing API calls between local and production, these all clicked through doing, not reading.

What I learned

Angular's structure is more opinionated than React, which turned out to be a good thing. Dependency injection, services as shared state, and the component lifecycle all started making sense once I stopped comparing everything to React and let Angular be Angular.

REWORN was also the first project where I got to bring my design background this directly into a larger frontend build. Designing something you're going to build yourself changes the way you design it. Decisions about layouts, reusable elements and interactions suddenly have consequences several components later. Sometimes that meant changing the code to fit the design. Sometimes it meant admitting the design was making my own life unnecessarily difficult.

It was also my first Supabase deployment, and my first time thinking seriously about what happens to an application after it's built, including the surprisingly practical problem of keeping a free-tier backend alive.

Turns out being both the designer and the developer doesn't eliminate handoff problems. You just get to argue with yourself instead.
